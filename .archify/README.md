# Archify diagrams

The main diagram is a self-contained HTML file. After cloning the repository, open this path in a browser:

```text
.archify/architecture-dsh-memory-20261031-012757/dsh-memory.html
```

It embeds its styles, fonts, SVGs, and viewer code, so it does not need a package install, a running development server, or network access. The `visual-check*` directories contain optional screenshots and contact sheets from the visual review. The JSON receipts and `candidate.json` record generation evidence; their audit fields may contain paths from the machine that generated the artifact.
