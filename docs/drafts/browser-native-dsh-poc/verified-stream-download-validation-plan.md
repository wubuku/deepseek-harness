# Workspace 验证下载流计划

## 决策问题与候选

[块对象实测](chunk-object-storage-validation-progress.md)已证明写入优化，也测到 64 MiB 冷恢复因 64 次 range 每次全文件校验而读取 4 GiB。本批验证能否在保持完整性、授权和有界内存的前提下，使一次完整下载的服务器 chunk 读取量与文件大小成比例。DSH-TUI 对状态连续性和取消所有权的启发用于下载生命周期；不引入 Shell，也不改变 Agent Loop、Session 或文件身份。

| 候选 | 价值与证据 | 安排 |
|---|---|---|
| 有界验证下载流 | 已测出直接的 64 倍读取放大，影响首次使用和缓存重建 | 本批 P0 |
| 取消、慢客户端、GC 并发 | 新流会持有引用与连接，必须证明释放和回收不丢 bytes | 本批 P0 |
| 浏览器损坏/中断后的缓存发布 | 网络成功不等于完整文件已验证，不能向 Agent 暴露部分文件 | 本批 P0 |
| 客户端 OPFS/Worker 内存预算 | 价值高，先验证本批不整文件缓冲，再独立做低内存矩阵 | 本批有限覆盖 |
| 旧 CDC 数据在线迁移 | 产品化必要，但不应与读取优化混合改变已有存储格式 | 后续 |
| 多实例 backend 与生产对象存储 | 需要跨实例事务、pin 与对象版本规则，不能以单进程代证 | 后续 |
| 长周期离线冲突与跨设备合并 | 需要产品冲突决策，已有 CAS 不是完整协作方案 | 后续 |
| Browser/Cloud 执行交接 | 高价值但属于执行权问题，与本批读取成本独立 | 后续 |
| 大型模型工具参数、附件和图片 | 应独立测试模型与 Session 载荷，不用文件流替代 | 后续 |

## 四个交付面

1. **存储读取。** 新增显式、临时的 verified reader：先完整校验 descriptor 与全部 chunks，捕获有界布局快照；随后只读取并校验即将返回的 chunk，下载期间保持引用，关闭或异常时释放。不缓存完整文件，不用 mtime 代替内容校验，不更改旧 range API 的强校验语义。
2. **HTTP 与浏览器。** 块对象 backend 显式协商版本化下载流；新入口仅接受当前 Workspace manifest 授权的文件。HTTP 采用背压与连接取消。浏览器顺序读取到 OPFS staging，校验总长度、流结束和完整 SHA-256 后才发布 cache/VFS；旧 backend/完整 blob 保留原下载方式。
3. **生命周期与失败。** 验证下载时来源被删除并运行 GC、取消、截断、同大小损坏、错误布局、backend 重启后重试。连接断开应释放 reader；未验证缓存不得变成已保存文件，失败不重放 prompt 或改变 operationId。不因慢网络长期持有全局 Workspace 写锁。
4. **实测与交付。** 同一确定性 16/64 MiB 输入在旧 range 与新流对照，冷 OPFS/IndexedDB、实际 HTTP 与 chunk 读取计数、单机耗时、GC 后 hash、负对照，以及独立真实 LLM 三轮 read/write/read 和刷新。记录失败和未验证项，启动可验收服务，提交并推送。

## 测量卡与验收

| 项目 | 判据 |
|---|---|
| 用户操作 | 同一 manifest 文件在清空浏览器 cache 后重新可读，UI/Host boot 完成，完整 hash 一致 |
| 输入 | 沿用确定性 binary 16/64 MiB，短尾、重复块、空文件另用单测；不读取用户真实文件 |
| 计时 | 从 Worker 冷恢复开始到缓存及 UI 可用；不含模型或准备上传；本机诊断无 CI 时间 SLA |
| I/O | 新流完整验证一次并返回时再验证每块，chunk 读取应不超过约两倍文件大小；旧 64 MiB 路径为 4 GiB |
| 内存 | store/HTTP 每次仅持有有界 chunk 和布局；OPFS 不先 arrayBuffer 整个响应 |
| 安全 | 猜 hash 不绕过 Workspace 授权；损坏、错序、截断均不能发布可见 cache |
| 生命周期 | active reader 阻止其引用被 GC；正常、异常、取消后引用归零且可回收；不占网络期间全局写锁 |
| 负对照 | 强制使用旧 range 时，新流请求/读取放大断言必须失败；不靠宽松耗时阈值判断 |
| 模型 | 真实 Chrome 与同源代理三轮 smoke 单独执行，不把确定性故障测试称为真实模型 |

若无法同时满足有界内存、完整性和引用释放，则记录受阻而不启用新协商。当前只验证单进程本地存储；不是生产多实例 pin 协议、自然 eviction、OS crash 或后台 Agent。
